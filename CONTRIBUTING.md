# Contributing to Runa

Runa is not open to code contributions. It's intentionally opinionated —
see [`RUNA.md`](./RUNA.md) — and is designed and maintained as a single
coherent point of view rather than a collection of independently accepted
patches. Pull requests will be closed unmerged, including small or
"obvious" fixes.

**Bug reports and feedback are very welcome.** If something doesn't work as
documented, or you have thoughts on the design, please open an issue. Use
the bug report template for defects and the feature/change template for
ideas or design feedback — you don't need to implement anything yourself.

By participating, you're expected to follow the
[Code of Conduct](./CODE_OF_CONDUCT.md). See [`SECURITY.md`](./SECURITY.md)
to report a vulnerability privately instead of via a public issue.
